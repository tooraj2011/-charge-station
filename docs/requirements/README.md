# Requirements

Store system, electrical, firmware, software, cybersecurity, safety, regulatory and manufacturing requirements here.

Recommended identifiers:

- SYS-REQ-xxx
- ELEC-REQ-xxx
- FW-REQ-xxx
- SW-REQ-xxx
- SEC-REQ-xxx
- SAFE-REQ-xxx
- MFG-REQ-xxx

Each requirement should have a source, rationale, verification method and status.
