# AI and Data

- `datasets/` — dataset definitions and metadata
- `power-quality/` — sag, swell, harmonics, transients, frequency, imbalance and interruption data
- `features/` — feature definitions
- `models/` — model metadata and versioned artifacts
- `edge/` — TinyML / edge inference
- `evaluation/` — accuracy, robustness and drift evaluation
- `digital-twin/` — AI-assisted simulation and digital-twin assets

Do not commit sensitive customer data. Track dataset provenance, sampling conditions and labeling methodology.
