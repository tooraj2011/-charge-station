# EV Charge Station Platform

Professional engineering repository for EV charging station hardware, firmware, software, communications, testing, certification, manufacturing, and field operations.

## Engineering Scope

- DC fast charging systems
- CCS2 and GB/T
- Power electronics and charger control
- STM32-based control and safety architecture
- OCPP 2.0.1, OCPI, ISO 15118
- Grid, PV, battery, generator and energy-management integration
- Diagnostics, telemetry and predictive maintenance
- AI/ML and edge intelligence for power quality and reliability

## Engineering Principle

Requirements → Architecture → Design → Implementation → Verification → Validation → Certification → Manufacturing → Field Evidence
