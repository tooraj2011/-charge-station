# Verification and Validation

- `unit/` — unit tests
- `integration/` — subsystem integration
- `hil/` — hardware-in-the-loop
- `electrical/` — voltage, current, power quality and protection
- `safety/` — interlocks, shutdown and fault handling
- `protocol/` — protocol conformance
- `system/` — end-to-end charger tests
- `reports/` — test evidence and signed/released results

Test cases should reference requirement IDs and record hardware/software revisions.
